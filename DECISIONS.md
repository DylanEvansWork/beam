# Decisions

## Dependencies (one-line justification each)
- `react`, `react-dom`: UI framework requested in spec.
- `vite`, `@vitejs/plugin-react`: build tooling.
- `typescript`: strict TS everywhere.
- `vitest`: unit tests for the engine (Node).
- `vite-plugin-pwa`: generates the service worker + manifest so the app works offline after first load. Supports Vite 8.
- `prettier`: formatting. `oxlint`: lint (ships with the Vite template).

## Design decisions
- **Max transfer size 1 MB for v1** (spec said 10 MB): fountain decoding with Gaussian-elimination fallback doesn't scale to ~50k symbols, and at realistic screen-to-camera speeds (a few KB/s) 10 MB would take 30+ minutes. Revisit with block segmentation if needed.
- **Icons are generated by `scripts/make-icons.mjs`** with a hand-rolled PNG encoder (zlib only), so no image tooling dependency. Placeholder art, polish in the last milestone.
- **tsconfig**: `strict` + `noUncheckedIndexedAccess` on, since the codec is all typed-array indexing.
- **Tests in `/tests`**, included in the app tsconfig so they're type-checked.
